================================================================================
НАСТРОЙКА РЕГЛАМЕНТНОГО ЗАДАНИЯ 1С: загрузка заказов с сайта каждые 5 минут
================================================================================

Предусловия:
  • Сайт пишет JSON в папку (ONEC_ORDER_EXPORT_DIR в .env бэкенда).
  • Тот же путь будет в константе 1С (ниже).

ВАЖНО про файловую базу (как InfoBase19 на диске):
  Фоновый запуск регламентных заданий в полной мере обычно даёт **сервер приложений
  1С** или опубликованная база. В «чисто файловом» режиме задания могут выполняться
  только при открытом сеансе 1С с правами администратора / полными правами или
  по кнопке «Выполнить сейчас». Для защиты диплома этого достаточно: показать
  расписание в конфигурации + ручной запуск + запись в журнал регистрации.

--------------------------------------------------------------------------------
ШАГ 1. Константа в конфигурации
--------------------------------------------------------------------------------

  1. Конфигуратор → дерево метаданных → «Константы» → Добавить.
  2. Имя: ПутьВходящихЗаказовИнтернетМагазина
     Тип: Строка (неограниченная или 500 символов).
  3. Значение по умолчанию: например
       C:\Users\User\Documents\ShopOrdersFor1C
     (строго тот же каталог, что на сайте.)
  4. Конфигурация → Обновить конфигурацию БД.

--------------------------------------------------------------------------------
ШАГ 2. Общий модуль
--------------------------------------------------------------------------------

  1. Общие → Общие модули → Добавить.
  2. Имя: РеглЗагрузкаЗаказовССайта (или своё — тогда поправьте имя в шаге 4).
  3. Свойства модуля:
       ☑ Сервер
       ☑ Серверный вызов разрешён  (в старых версиях: «Вызов сервера»)
  4. Откройте модуль, вставьте КОД из файла:
       CommonModule_РеглЗагрузкаЗаказовССайта.bsl.txt
     (только содержимое между #Если … #КонецЕсли, без комментария-шапки файла
     или вместе с ним — шапку можно не копировать).
  5. Сохранить, обновить конфигурацию БД.

--------------------------------------------------------------------------------
ШАГ 3. Регламентное задание
--------------------------------------------------------------------------------

  1. Общие → Регламентные задания → Добавить.
  2. Имя: например ЗагрузкаЗаказовИнтернетМагазина.
  3. Имя метода (обработчик): в точности как в вашей версии платформы, обычно:
       РеглЗагрузкаЗаказовССайта.ВыполнитьЗагрузкуЗаказовССайта
     То есть: <ИмяОбщегоМодуля>.<ИмяЭкспортнойПроцедуры>
     Если модуль назвали иначе — подставьте своё имя.
  4. Использование: включено.
  5. Расписание:
       • либо в свойствах задания задать «Каждые 300 секунд» / интервал 5 минут
         (формулировки в UI зависят от версии);
       • либо через отдельное расписание (если в конфигурации так принято).
  6. Обновить конфигурацию БД.

--------------------------------------------------------------------------------
ШАГ 4. Режим 1С:Предприятие (не конфигуратор)
--------------------------------------------------------------------------------

  1. Войти под пользователем с правами на регламентные задания (часто «Полные права»).
  2. Администрирование → Регламентные и фоновые задания (или только Регламентные).
  3. Найти «ЗагрузкаЗаказовИнтернетМагазина» — статус должен быть активен.
  4. При необходимости выполнить вручную «Выполнить сейчас» для проверки.

--------------------------------------------------------------------------------
ШАГ 5. Проверка
--------------------------------------------------------------------------------

  1. Оформить заказ на сайте — в папке появляется order_<id>.json.
  2. Дождаться срабатывания РЗ (или запустить вручную).
  3. Файл должен переместиться в подпапку «обработано».
  4. Журнал регистрации: событие «ИнтернетМагазин.ЗагрузкаЗаказов» — уровень Информация,
     текст «Принят заказ с сайта № …».

Если «Имя метода» не находится в списке — проверьте флаги общего модуля (Сервер,
серверный вызов) и что процедура объявлена с Экспорт.

--------------------------------------------------------------------------------
Дополнительно
--------------------------------------------------------------------------------

  • Создание реального документа учёта — в том же модуле, вместо закомментированного
    блока (см. HOW_TO_IMPORT_IN_1C.txt).
  • Папка «обработано» создаётся автоматически рядом с входящими JSON.
